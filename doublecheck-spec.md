# Doublecheck spec

## Goal
Foreground the user's AI engineering work across every CV surface — four AI focus areas in the Chubb role plus the personal AI products Clarif-AI (clarif-ai.net) and DeepIndex (npm) — by updating portfolio-main-data.json and extending every generated output it feeds, with the printable resume kept to a single unclipped A4 page, a green suite run, and commits on record.

## Scope
In: src/data/portfolio-main-data.json (Chubb responsibilities → 7 AI-forward bullets; Clarif-AI + DeepIndex project entries at top; Innovation skill group → 7 tags; about.description V1; meta keywords +AI terms). scripts/generate-static-resume.js — redesigned per user instruction: education moved to sidebar, skills merged to 2 groups (Engineering + AI & Innovation, reduced tag count), projects as 2-column cards (top 2, 4-line description clamp), 3 articles in PDF sidebar — data file untouched by these layout choices. public/resume-export.html regenerated. scripts/verify-resume-content.js acceptance test (28 checks incl. redesigned-layout checks). Render verification via gsd-browser + localhost server + flatpak Chrome. Repo suite (build per CI, typecheck hygiene). Three commits total. Out: everything else — see non-goals.

## Acceptance criteria
1) portfolio-main-data.json is valid JSON; tsc --noEmit exits 0. 2) All three data-fed surfaces carry the change: site components (CLI outputs + in-app resume modal read the JSON directly); regenerated public/resume-export.html contains "Clarif-AI", "DeepIndex", "PROJECTS.BIN", the AI skill tags, and the new Chubb bullets (verified by grep in the built artifact). 3) scripts/verify-resume-content.js exits 0 — including redesigned-layout checks: EDUCATION.BIN in sidebar before SUMMARY.EXE, project-grid cards present, skills merged to Engineering + AI & Innovation groups, SDK4ED-TD absent. 4) Render proof via gsd-browser (Chrome print): probe PDF (clip removed) = exactly 1 A4 page; real PDF text contains education entries AND the ISTQB cert ID GRTB-24-1S20-CTFL (the line previously clipped). 5) npm run build (CI suite) exits 0. 6) Each batch committed after its green run.

## Failure modes
Invalid JSON or schema mismatch → typecheck/build red → fix before shipping. Template edit breaks build:resume → non-zero exit → fix, regenerate. Silent propagation gap → grep the built HTML, not eyeball the site. Print-fit regression → probe-PDF page count + pdftotext content check via gsd-browser render (screen math alone proved unreliable — actual overflow was 234px vs ~6px estimated). Entity confusion (clarif-ai.app lookalike) → links verified against live domain + npm registry. Unapproved personal copy → all copy draft-approved verbatim; summary V1 confirmed; card descriptions clamped to 4 lines is presentation-only (full copy behind links + on site). flatpak Chrome cannot see host file:// paths → serve over localhost HTTP instead. Untracked scratch artifacts in public/ → deleted before commit so they never deploy. Rollback: three sequential commits, each git-revertable.

## Priorities
Approved copy verbatim over template elegance; no content loss in print over compactness (render-verified, not estimated); single A4 page per user's redesign; cross-surface consistency except where the PDF layout deliberately diverges (sidebar education, merged skills, card projects); minimal diff (reuse existing template classes). Pressure valves if print overflows again: fewer sidebar articles, then tighter print margins — never silent clipping.

## Non-goals
No AI-first V2 rewrite of the about summary (V1 chosen). No edits to non-AI CV entries in the data file. No component/TSX code changes — data drives them. No Clarif-AI sourceUrl (no public repo named). No changes to the site/in-app skill grouping (4 groups stay; merge is PDF-template-only). No push/deploy to master (CI deploys on push — separate explicit action). No GSD Explore-Visual-Landing milestone work. No new ~/.dsh skill files. No ESLint initialization (repo has none; CI runs build only).
